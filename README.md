# Proyek Website HTML Sederhana

Website sederhana yang dibuat menggunakan HTML dan CSS, langsung dari HP.

## Fitur
- Halaman web responsif
- Navigasi sederhana
- Cocok untuk latihan dasar frontend

## Cara Menjalankan

1. Download atau clone repositori ini
2. Buka file `index.html` di browser (bisa lewat HP atau laptop)

## Teknologi yang Digunakan
- HTML5
- CSS3
